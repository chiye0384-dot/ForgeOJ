# 在自己的电脑上打开 ForgeOJ

双击仓库根目录的 **打开ForgeOJ.cmd**，等待出现 Ready 后会自动在默认浏览器打开。也可手动访问：

http://127.0.0.1:8088/problems

演示账号：learner；密码：forgeoj-dev-only。这是本机测试身份，不要填写真实个人资料。电脑和 Docker Desktop 必须保持运行。此地址只供当前电脑使用，不是公网网址。

2026-10-30已验证：21题、Java入门20题官方题单、真实判题与保留数据停启均可用。自动验收提交属于独立 verification-learner 账号，不代表你的学习成绩。正式注册邮件尚未配置，本机练习使用 learner。点击页面顶部“账号”即进入登录，仅填写用户名或邮箱、密码；新用户点击“注册账号”。本地页面会标明邮件模拟限制。邮箱确认后自动登录的流程已用隔离测试身份验证。

PowerShell 命令（先进入 ForgeOJ 文件夹）：

做题页左侧可切换题目、官方题解、自定义自测、题目反馈，右侧代码默认自动换行。桌面拖动中间分隔线调整宽度，双击恢复；也可点击“展开代码区域”。21题均有官方题解，通过当前版本后解锁，或按页面提示明确确认提前查看。提交记录仍进入学习记录。

```powershell
.\ForgeOJ.ps1 -Action Start
.\ForgeOJ.ps1 -Action Status
.\ForgeOJ.ps1 -Action Stop
```

Start 编译当前前端，核对后端构件摘要，按依赖顺序启动已初始化的演示项目，检查页面和 API 后显示网址。Stop 只停止核对归属后的准确容器，不删除提交、容器或数据库卷。关闭 Codex 不参与启动/停止流程。

若 8088 被占用，可使用 `-Port 8089`；成功启动后 Status 会记住该入口。不得通过停止其他项目抢占端口。

已初始化项目的选择保存在 ignored 的 `target/local-demo.json`。首次兼容现有明确归属的演示状态目录；选择新的已初始化演示时，传入 `-RunDirectory target/forgeoj-e2e-日期-时间-标识`。只接受当前仓库 target 内目录、匹配的项目标签和已记录的 JAR 摘要。缺少状态或数据卷时命令会停止，不自动创建空库覆盖历史。

`-SkipFrontendBuild` 只供明确知道当前 dist 已构建的验证流程使用。后端源码变更后必须先重新构建/验证，显式核对构件来源和数据库兼容性再更新或选择演示；Start 不会把旧 JAR 描述成最新后端。注册邮箱和真实 SMTP 不属于本机演示入口；本机练习使用上述演示账号。

公网长期访问另需持续运行的服务器、可达入口与 HTTPS，仍按 M5 部署计划单独验收。
