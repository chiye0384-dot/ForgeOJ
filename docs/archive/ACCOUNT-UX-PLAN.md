# 账号入口与注册流程修复

2026-10-30，用户明确要求修正账号默认注册、找不到登录入口的问题。本单元 VERIFIED（本地账号流程修复）；此前本地使用改进的验收不覆盖本次新变更。

1. `/account` 匿名默认登录，仅要求用户名或邮箱、密码。显式点击注册才出现注册字段，昵称可选。已登录显示账号管理。
2. 普通用户受保护页面统一跳至登录，保留站内返回位置；公共题库可匿名浏览，管理员认证保持独立。
3. 保留已确认的邮箱验证规则。注册提交后明确显示待验证；用户确认邮件后，在同一事务完成激活和创建会话，直接登录。密码不保存在浏览器存储或链接中。
4. 登录、注册、激活、找回密码、账号安全各有清晰标题和按钮，错误时不假装成功。
5. 覆盖匿名导航、登录返回、注册切换、激活自动登录、令牌重用/失败/事务回滚和现有账号回归；构建并更新实际本地入口，再通过真实页面检查。

整组额度已核：五小时已用36%、周53%。估算包括实现、必要前后端验证、一次合理修复与证据保存，可开展；扩大重试前重新评估。不触及真实邮件、公网部署和保护文件，保留现有题目与数据。

实施补充：注册、重发和找回使用明确子路由，点击顶部账号可恢复默认登录。真实页面发现同一路径的邮件 fragment 不触发重新挂载，已改为监听链接变化并在请求前清除地址及路由历史中的令牌。仅本地演示网关注入环境标记，页面据此显示公开演示账号和邮件模拟说明；正式构建默认不显示这些提示。
